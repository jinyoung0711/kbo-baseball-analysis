# ⚾ KBO 투수 성적 분석

## 📌 프로젝트 개요
KBO 리그 투수들의 성적에 영향을 미치는 요인을 분석하는 프로젝트입니다. 투수 성적의 핵심 지표인 **WHIP**(이닝당 허용한 안타와 볼넷의 합)과 구장별 특성을 나타내는 **파크팩터**(Park Factor)가 투수 성적에 미치는 영향을 분석합니다.

## 📊 데이터
- **출처**: [Statiz](https://www.statiz.co.kr)
- **기간**: 📅 2023년 시즌 기준
- **데이터 형식**: 📂 CSV
- **파일 구성**:
  - `baseball_data/`
    - 📁 `WHIP_park.csv`: WHIP과 파크팩터 데이터를 포함한 파일
    - 📁 `basic.csv`: 기본 투수 성적 데이터
    - 📁 `pitching.csv`: 상세 투구 기록 데이터
    - 📁 `plus.csv`: 추가 성적 지표 데이터
  - 📜 `baseball_code.ipynb`: 데이터 수집, 전처리 및 분석 코드

## 🎯 분석 목표
1. 🏟️ 구장별 특성이 투수 성적에 미치는 영향을 분석합니다.
2. 📉 WHIP과 파크팩터 간의 상관관계를 탐색합니다.
3. 📈 투수 성적과 관련된 추가 변수(ERA, 삼진율 등)의 영향을 평가합니다.

## 🔍 분석 과정
1. **데이터 수집**: 🕵️ Statiz에서 투수별 성적 데이터를 크롤링합니다.
2. **데이터 전처리**: 🛠️ 결측치 처리 및 변수 변환을 수행합니다.
3. **데이터 분석**:
   - 🏟️ 구장별 파크팩터 계산
   - 📊 WHIP과 파크팩터의 상관관계 분석
   - 🔬 추가 변수들과의 관계 분석
4. **결과 해석**: 📌 분석 결과를 시각화하고 해석합니다.

## 🏆 주요 결과
- 🏟️ 구장별 파크팩터는 투수의 WHIP에 영향을 미치는 것으로 나타났습니다.
- ⚾ 특정 구장은 투수에게 유리하거나 불리한 환경을 제공할 수 있습니다.
- 📊 WHIP은 투수의 전반적인 성적을 평가하는 데 유용한 지표입니다.

## 🚀 향후 계획

- 🤖 머신러닝 모델을 활용한 투수 성적 예측
